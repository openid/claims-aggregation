# Contributing to OpenID Connect Claims Aggregation

## Contribution Agreement

Before contributing to the specification, make sure you are covered by a signed
[OpenID Foundation Contribution Agreement](https://openid.net/intellectual-property/openid-foundation-contribution-agreements/)
for the [AB/Connect Working Group](https://openid.net/wg/connect/). If you
contribute on behalf of an organization, you can participate as its designated
representative under the organization's signed agreement for the working group.

## Issues

Search the [existing issues](https://github.com/openid/claims-aggregation/issues)
before opening a new one. Choose **Specification feedback** and include the
draft version and section number, if applicable. Explain what needs to change
and include proposed wording if you have it.

## Pull requests

Make specification edits in the
[Markdown source](openid-connect-claims-aggregation-1_0.md). Describe the
change and link to any related issue.
